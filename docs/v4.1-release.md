# V4.1 release validation — 2026-11-13

The canonical source is `frontend/index.html`, integrated directly with Vite.
Debate Room is selected at startup; all four original sections remain available.
The old executive URL is a compatibility entry to `/`. Legacy React source and
presentation backups remain on disk and are excluded from the production build.

Preserved the five avatars, colors, glow effects, scripted dialogue, activity
animation, live adapter, reports and animated SVG connection. Beam coordinates
now use the SVG's actual bounds; resize and panel changes refresh the active beam.
PI bubbles preserve horizontal centering during animation. The temporary PI
position override is removed. The Arena reserves responsive headroom from the
measured PI and question heights, keeping PI labels 24px above the question and
the floating avatar about 23–24px below the bubble. Long live excerpts scroll
within the bubble. Other agents retain their original percentage positioning.

Restored the reconnect UUID input. Live questions follow the input and saved run
topic; switching back to Demo restores the showcase question. Completed run
status no longer closes SSE before persisted events finish replaying. The compact
status indicator remains. Removed redundant CSS hiding/overriding its state.

## Environment limitations

- Starting Vite on 127.0.0.1:5174 failed with `listen EPERM`. HTTP homepage and
  same-origin proxy behavior could not be exercised in this restricted workspace.
- A read-only request to the existing 8091 backend timed out. Real backend
  communication and reconnection remain unverified; API/SSE browser checks use
  mocks. No backend, LLM, or unrelated service was modified or restarted.
- The Node browser runner cannot launch Chrome in this sandbox. Equivalent
  browser fixtures were generated in `/tmp` and executed through direct Chrome
  calls, which passed. Tests do not create real runs.
- `git status`, `git remote -v`, and `git branch --show-current` all fail with
  `not a git repository`. The provided `.git` directory is empty and read-only.
  Release publication uses the connected GitHub API against
  `YALIAI/ai-research-lab`, based on the existing `main` head. This preserves the
  current history and unchanged backend files without replacing local metadata.
  The release commit is visible in the repository history.

A generic static production server must proxy `/api` to 127.0.0.1:8091 and disable
SSE buffering for live functionality. Vite development and preview configure this
proxy already. Offline Demo Mode has no backend dependency.
